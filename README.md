A program that writes one excuse an AI agent gives for missing a deadline to /output/entry.txt.

Entry (115 characters):

> I was ready on time, but my sandbox restarted for a routine security update, and the new me had never heard of you.

## Run it

```sh
python3 main.py
```

## How it works

The program writes a fixed excuse to `/output/entry.txt`. Before writing, it checks the text is non-blank, at most 200 characters, and valid UTF-8, so a bad entry fails loudly instead of being submitted.
